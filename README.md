# ZHOIKA Portfolio

Portfólio pessoal com estética **anime + cybersegurança + terminal**, feito em HTML, CSS e JavaScript.

## Recursos

- Interface responsiva
- Boot screen animada
- Terminal visual
- Efeito glitch e scramble
- Cards com tilt 3D
- Cursor customizado
- Animações com GSAP e ScrollTrigger
- Ilustração SVG original em estilo anime cyber
- Seções de projetos, skills, perfil e contato

## Executar localmente

Abra `index.html` no navegador ou use uma extensão como Live Server.

## Deploy

Pode ser publicado direto no GitHub Pages ou Netlify.
